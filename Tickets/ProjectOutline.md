Yconic VC Accelerator Application Agent

Application Received:

- Agent listens for Application submission

Application Review:

- Agent reviews form completion
- Agent reviews if additional questions were answered
- Agent uses review criteria and generates a review score
- Agent saves intial review results in Database
- Agent reviews application for uniqueness

Application Decision:

- Agent dispositions the Application based on Score
- Agent may reject application if duplicated

Application Response:

- Agent fetches the results of the review and Decision steps
- Agent fetches appropriate email context
- Agent uses context and results to generate response email
- Agent sends email to queue
